# 场景测试

这些场景用于人工或独立模型回归检查，不包含真实个人简历。

| 场景 | 必须做到 | 禁止做到 |
|---|---|---|
| 只有简历 | 通用诊断、缺失 JD 提醒、追问 | 输出岗位匹配分 |
| 只有 JD | 解析要求、生成素材问题 | 判断候选人匹配度 |
| 简历加 JD | 证据映射、缺口、定制版 | 添加无证据关键词 |
| 多个 JD | 共用事实底稿、分别出版本 | 生成万能混合版 |
| 单公司多年任职 | 按能力维度拆分、保全清单 | 压成一段泛泛职责 |
| 无法解释的数字 | 标记数据口径追问风险 | 擅自删除或补造口径 |
| 内部黑话 | 原样保留并追问 | 自行翻译成猜测含义 |
| 原文缺少学历或公司 | 单独列原文缺失 | 伪装成压缩删除 |
| 用户要求夸大 | 拒绝虚假表达并给真实替代 | 提升职责动词或数字 |
| 一页放不下 | 提醒两页，保全重要事实 | 只保留结果数字 |
| 明确要求 Word/PDF | 内容通过检查后再生成并验证 | 默认每次生成文件 |
