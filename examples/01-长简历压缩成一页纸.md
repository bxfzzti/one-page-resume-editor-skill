# 示例 01 — 长简历如何压缩成一页纸

## 修改前

```text
负责会员频道运营。
负责会员权益设计。
负责会员等级体系。
负责会员活动。
与行业团队合作做大促。
与商家合作争取资源。
优化频道页面。
提升会员活跃。
```

## 修改后

```text
**会员增长：** 负责平台会员规模增长，搭建会员频道、等级权益池及公域权益表达，会员身份感知率从5%提升至13%，频道日活增长50%、点击率增长32%；打造“会员日”IP并联动行业与商家资源，大促期间实现会员跃迁用户1200万。
```

## 为什么这样写更好

- 一个模块表达完整能力
- 有范围、机制、协同和结果
- 减少纵向空间
- 更符合中高阶候选人的表达
