# 示例 03 — 协同经验不等于行业经验

## Source Facts

候选人在精品电商平台负责私域增长，并与食品、日化家清类目团队协同探索首购和复购玩法。

## Risky

```text
具备食品、日化行业经验。
```

## Better

```text
**复购提频与行业协同：** 协同类目团队在私域探索“整点抢券、爆品直降、0元免单”等促活提频玩法，并打通App与微信消息通道，推动28天复购率提升至原来的1.67倍；通过首购、复购策略优化，7天用户价值从8.3提升至10.7。
```

## Rule

写清自己的机制与共同结果，不把协同关系升级成行业 ownership。
