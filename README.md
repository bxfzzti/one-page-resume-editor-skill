# 一页纸简历修改器

面向 **5 年以上中高阶求职者** 的中文简历整理与岗位定制 Skill。通用支持各职业方向，第一版重点深耕产品、运营、用户增长、商业化、平台和电商岗位。

它不是独立智能体，也不是普通润色提示词，而是一套可被 Codex、Claude Code 或其他智能体调用的中文简历工作规则。

## 它解决什么问题

- 简历很长，但招聘方看不出职业定位
- 经历写成职责流水账，缺少背景、动作、结果和个人贡献
- 长期任职、短经历、转行或空窗期不知道怎么组织
- 有内部黑话、团队成果和数据，但担心面试时解释不清
- 想按多个 JD 定制，又不希望被改写成另一个人
- 需要一页核心版，但不想为了页数丢掉关键经历

## 四类用户任务

1. **看看简历问题**：输出定位、证据、结构、时间线、权重和主要风险。
2. **整理成一页纸简历**：输出一页核心版；如果保全重要事实会受损，提醒改成两页。
3. **按 JD 定制简历**：输出岗位要求、证据映射、真实缺口和 JD 定制版。
4. **检查简历和准备面试**：输出逐条追问、数据口径风险、贡献边界和补充问题。

没有 JD 时只做通用诊断或整理，并明确说明不能完成岗位匹配。Word/PDF 只在用户明确要求时生成。

## 推荐使用方式

```text
请看看我的简历有什么问题。
先给出定位、最重要的 3 个问题、经历优先级和需要补充的信息，暂时不要重写整份简历。
```

```text
请把我的简历整理成一页纸简历。
不要修改数字、公司名、岗位名和业务黑话；所有删除内容都列出原因，无法确认的信息先标记。
```

```text
请按下面这个 JD 定制我的简历。
先做 JD 要求和事实证据映射，再生成定制版；没有证据的关键词不要添加。
```

```text
请按下面两个 JD 分别定制我的简历。
使用同一份事实底稿，分别输出每个 JD 的证据映射、定制策略和版本修改记录，不要混成一份万能简历。
```

```text
请检查我的简历，并准备面试追问。
逐条检查我的负责范围、个人贡献、数据口径、协作者边界和结果归因。
```

## 真实性原则

- 用户提供的数字、事实、公司名、岗位名、专有名词和内部业务表述不能被模型自行改写。
- 不能把参与写成负责，把协作写成主导，把团队结果全部归给个人。
- 不理解的黑话先追问，不自行翻译。
- 删除记录与原文缺失清单分开。
- 信息不足时先追问，不用猜测补齐。

## 交付层级

默认先交付内容：诊断、简历正文、JD 定制版、修改记录和风险说明。用户明确要求时，再生成可编辑 Word、可投递 PDF，并验证实际页数、文本可复制性和基本可读性。

Word/PDF 是内容确认后的文件化阶段。成功标准不是文件存在，而是渲染后页数、可复制文本、可读性和内容一致性通过检查。

默认目标是一页；如果一页会明显损失重要经历或叙事完整性，会提醒用户采用两页版本。
