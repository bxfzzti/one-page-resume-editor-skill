# 一页纸简历修改器

适合 **5 年以上中高阶求职者** 的简历诊断与改写技能。

它不是简单润色工具，而是先自动识别简历里的核心问题，再给出可执行的修改建议，帮助你把复杂经历压缩成一份定位清晰、证据充分、可面试、可投递的一页纸简历。

这个仓库提供的是 `SKILL.md`：一套可被 Codex、Claude Code 或其他智能体调用的简历修改规则、流程和示例。它本身是技能，不是独立智能体。

## 适用场景

- 简历太长，项目像流水账
- 多段经历之间缺少清晰职业主线
- 不知道哪些经历该展开、哪些该压缩
- 有数据和成果，但表达不够有说服力
- 担心简历写得太虚、太夸大，面试时撑不住
- 想根据 JD 做定制，但不想改到失真

## 核心能力

1. **诊断问题**：先评分，再判断是否需要重写
2. **给出建议**：指出定位、证据、结构、权重、风险等问题
3. **压缩经历**：把长简历整理成一页纸简历
4. **按 JD 定制**：基于已有事实做 10%–15% 的受控调整
5. **审查风险**：检查夸大、黑话、归因不清和面试不可解释的表达

## 术语原则

面向用户的说明一律使用中文表达：

- 诊断模式
- 一页纸简历模式
- 定制模式
- 审查模式

不使用 `MASTER`、`TAILOR` 这类英文模式名。只有 `SKILL.md`、`README.md`、仓库地址、技能标识等平台约定名称保留英文或代码格式。

## 使用方式

### 1. 先诊断，不急着改

```text
请阅读 SKILL.md，并用“诊断模式”分析我的简历。
请给出各维度评分，识别职业主线，划分经历权重，
并列出最重要的 3 个问题。
先不要直接重写完整简历。
```

### 2. 生成一页纸简历

```text
请阅读 SKILL.md。
请用“一页纸简历模式”生成一份中文一页纸简历。
所有表达都要经得起面试追问。
不要虚构数据。
```

### 3. 输入 JD 做轻定制

```text
请阅读 SKILL.md，并用“定制模式”处理。
请对比我的基础简历和目标 JD，
提取最重要的 3 个要求，建立证据映射，
计算匹配分，识别差距，并且只做 10%–15% 的轻定制。
不要增加没有事实支撑的关键词或经历。
```

### 4. 只审查风险

```text
请阅读 SKILL.md，并用“审查模式”处理。
请找出表达夸大、数据薄弱、内部黑话、
职责重复、时间线问题和经历权重错误。
```

## 诊断维度

总分 100，维度包括：

| 诊断维度 | 权重 |
|---|---:|
| 定位清晰度 | 15% |
| 证据强度 | 20% |
| 高阶感 | 15% |
| 职业主线 | 15% |
| 信息密度 | 10% |
| 岗位匹配准备度 | 10% |
| 真实性与可解释性 | 10% |
| 外部可读性 | 5% |

解释：

- 90–100：强，只需轻定制
- 80–89：有竞争力，做定向优化
- 70–79：可用，但定位或权重有问题
- 60–69：建议重写
- <60：建议结构性重建

## 改写原则

好的中高阶简历不是职业档案，而是招聘决策界面。

它应该让招聘方快速判断：

1. 这个人做过足够复杂的工作；
2. 这个人拿到过可验证的结果；
3. 这个人的能力可以迁移到当前岗位。

默认只按 JD 改动母版的 **10%–15%**。

允许：

- 调整摘要顺序
- 调整模块顺序
- 前置相关证据
- 用 JD 可理解的词替换泛化表达
- 压缩无关经历
- 增加已有证据支持的关键词

禁止：

- 虚构经验
- 把协同写成负责
- 把行业接触写成行业负责
- 添加未证实的语言、工具、市场经验
- 为模仿 JD 重写 50% 以上
