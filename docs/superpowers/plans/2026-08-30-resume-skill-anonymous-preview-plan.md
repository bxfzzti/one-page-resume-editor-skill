# 匿名公开验证版实施计划

## 目标

在不删除手机号登录、积分和支付代码的前提下，增加可切换的匿名公开验证模式。

## 实施步骤

- [x] 增加匿名用户字段、匿名额度表和数据库迁移。
- [x] 实现匿名会话创建、当前模式查询、每日额度消费和过期清理。
- [x] 让简历保存与任务创建支持匿名用户，并限制验证版服务范围。
- [x] 修改首页、上传页和工作台文案，隐藏登录、积分和购买主路径。
- [x] 增加匿名模式单测、API 测试和桌面/移动端 E2E。
- [x] 运行迁移、单测、lint、类型检查、构建和真实浏览器验证。
- [x] 同步安装副本并完成提交前交付检查。

## 不在本次范围

- 真实短信供应商、微信登录、正式支付、公网部署、域名和备案。
- 自动清理正式用户数据。
- 将匿名简历用于模型训练。
